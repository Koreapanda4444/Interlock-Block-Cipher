# 연구 진행과 남은 과제

현재는 초기 저장소 생성 커밋을 제외한 연구 커밋 44개다. 커밋 번호는 IN 작업
번호와 다르며 IN-044 또는 페이즈 6 완료를 뜻하지 않는다. 이번 구간에서
암호 코어·규범 명세·KAT를 바꾸지 않았다. 보안 강도·독창성은 미확정이다.

| 페이즈 | 작업 범위 | 현재 근거 | 남은 핵심 과제 |
|---|---|---|---|
| 1 | IN-001~008 | 단일 명세, 갱신·역변환 증명, SHAKE 인코딩 | 선행 설계와 동치·독창성 비교 심화 |
| 2 | IN-009~017 | C11 API와 독립 KAT·중간값·역변환 구현 | 기본 구현·기능 회귀 완료 |
| 3 | IN-018~024 | FS 노출, 부품 표, FM 국소 편향, 위험 유지 결정 | 국소 위험을 고라운드 공격으로 연결하고 재설계 여부 판단 |
| 4 | IN-025~033 | 1라운드 전체 서브키 복원, 1~3라운드 차분, 모든 키의 1/2라운드 boomerang, 1~8라운드 유한 검사 | 최적 trail/hull, 고라운드 키 복원, MITM·slide |

## 재현과 산출물

```sh
make all check research
python3 -m pip install -r research/requirements-smt.txt
make smt-check smt-research
make fuzz-check
make fuzz CC=clang
make ct-check
make measure
```

일반 연구는 C11 컴파일러·Make·Python 표준 라이브러리만 필요하다. SMT는
고정 Z3 패키지, ct-check는 Valgrind와 헤더, mutation 퍼징은 Clang이 필요하다.
측정은 POSIX 시계와 binutils의 size/objdump를 사용한다. 컴파일러·옵션을
바꾸거나 sanitizer 실행 뒤 일반 공유 라이브러리로 돌아갈 때는 먼저 clean한다.

일반 full 묶음은 **19실험·10550568블록 평가**다. 역방향 쿼리와 재검증도
포함하며 고유 평문 수나 최적 공격의 쿼리 복잡도와 다르다. 부품 평가는 별도다.
SMT full 묶음은 **7실험·107블록 평가**이며 모델 계수용 SAT·종료 결정도 모두
기록한다. SAT/UNSAT/UNKNOWN 개수는 공격 성공/보안 합격 수가 아니다.
이전 9실험·8251624블록과 18실험·10288424블록은 과거 묶음의 집계다.

각 일반 하위 실험은 프로세스 제한 60초, 묶음의 협력적 시간 제한 180초다.
SMT도 하위 프로세스 제한 60초·묶음 180초이며 개별 solver timeout/rlimit은
각 JSON에 별도로 기록한다. 초과·누락·불일치는 성공으로 바꾸지 않는다.
보고서·SMT2·측정/동적 감사 로그·생성 코드는 build 및 CI artifact로 제공하며
artifact 보존 기간은 7일이다. 생성 바이너리·원시 보고서는 커밋하지 않는다.

## 남은 연구와 유지 결정

첫 라운드 서브키 복원과 모든 키의 2라운드 구별자는 재현된 축소라운드 결과다.
공개 API는 28라운드만 제공하며 위 공격의 축소 순열 오라클을 직접 제공하지 않는다.
12/20/28라운드의 낮은 차분 무게 탐색은 현재 예산에서 UNKNOWN이다.
이를 안전성 근거로 사용하지 않는다. 선형 큐브의 정확한 상관도 나머지 평문
비트를 고정한 제한 함수의 값이며 전체 128비트 입력의 hull 상계가 아니다.

현재 결정은 **연구용 코어 유지, 실사용 안전성 승인 보류**다. 다음 핵심 과제는
알려진 부품 편향·축소라운드 구조를 미지 키의 고라운드 공격으로 확장하거나,
그 한계를 엄밀하게 분석하는 일이다. 전체 차분/선형 hull, MITM·slide,
마스터키/관련 키, 선행 설계와의 동치 가능성과 외부 독립 검토가 남아 있다.
고라운드 공격이나 보안 여유 부족이 확인되면 명세·코어·KAT를 함께 바꾸고
기존 분석을 무효화한 뒤 재검증한다.
