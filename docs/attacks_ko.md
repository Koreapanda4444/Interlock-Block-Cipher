# Interlock 추가 공격 분석

이 문서는 현재 단일 코어를 대상으로 한 18커밋 이후의 근거를 정리한다.
규범 수식은 `spec_ko.md`, 전체 위험과 결정은 `security_ko.md`를 따른다.
명세·코어·KAT는 변경하지 않았으며 새로운 평문 오라클 분석과 내부 부품
관측 모델을 구분한다. 분석 스크립트의 종료 성공은 보안성 합격이 아니다.

## FS의 부호 있는 선형 상관

`research/linear.py`는 L의 전치 `L^T(x)=x xor ROR(x,3) xor ROR(x,17)`를
32×32 기저 내적으로 확인하고 `(L^T)^-1=(L^T)^31`을 검사한다.
균등 32비트 입력, 고정 서브키 k에 대한 FS의 상관은 정확히
`(-1)^<alpha,k> * product_i LAT[alpha_i,(L^T beta)_i]/16`이다.
니블별 독립성과 입력 XOR 키의 위상 변화로 얻으며, 라운드 간 독립 가정은 없다.
4개 키·8개 활성 니블·225개 비영 마스크 쌍의 7200개 상관을 C FS 출력과
전수 대조한다. 부호와 상관/편향(상관의 절반)을 구분해 저장한다.
`python3 research/linear.py`로 재현한다.

## 외부 블록 오라클의 선형 구별식

1라운드의 두 번째 출력 단어는 `ROL(a xor FS(b,k0),13)`이다.
FS의 마스크 alpha,beta를 선택하면 평문 마스크 `(beta,alpha,0,0)`와
암호문 마스크 `(0,ROL(beta,13),0,0)`의 상관은 FS 상관과 정확히 같다.
LAT 절댓값 8인 한 니블 마스크를 사용하면 모든 키에서 절댓값 1/2이며
위상만 k0에 의존한다. 훈련 평문으로 위상을 추정하고 겹치지 않는 검증
평문으로 부호·상관·편향을 기록한다. 공격 자체는 내부 키를 읽지 않는다.
실험의 정답 대조에만 실제 키 스케줄을 사용한다.
`python3 research/linear.py --cipher`는 고정한 동일 마스크를 1~8라운드에서
측정한다. 2라운드 이상의 수치는 관측이며 선형 hull의 상계가 아니다.
